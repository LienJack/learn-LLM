# LLM システム学習教材プロジェクト

言語: [中文](../README.md) | [English](../en/README.md) | 日本語

これは API チュートリアルではありません。概念だけを説明する入門記事でもありません。

本プロジェクトは、実行でき、テストでき、変更でき、再現できる中国語ベースの LLM システム学習教材です。最小限の訓練ループから出発し、言語モデル、Tokenizer、Attention、Transformer、微調整、RAG、蒸留、評価、そしてドメイン特化の小規模モデル開発へと段階的に進みます。

この教材では、Python の基礎知識があることを前提にしています。一方で、深層学習、確率モデリング、情報理論、GPU 訓練、分散システムを体系的に学んでいることは前提にしていません。

## 教材の軸

本教材は、次の中心的な問いに沿って進みます。

> モデルが文脈に基づいて信頼できる回答を生成するには、どの能力をどの順番で補う必要があるのか。そして、それらの能力は実験、テスト、失敗事例によってどのように検証できるのか。

この軸は 5 つの層に分かれます。

1. **最適化層**: モデルが loss、計算グラフ、勾配、optimizer を通じて、誤りからどのようにパラメータを更新するか。
2. **系列モデリング層**: 言語モデルが「文章の続きを書く」という問題を next-token probability にどのように変換するか。
3. **表現と構造の層**: Tokenizer、Embedding、Attention、Transformer が、テキストを計算可能で訓練可能、かつ組み合わせ可能な文脈表現へどのように変換するか。
4. **適応と拡張の層**: SFT、LoRA/QLoRA、RAG、蒸留を使って、汎用モデルを実用的なタスクモデルへどのように変えるか。
5. **エンジニアリングガバナンス層**: 評価、安全性、モデルカード、デプロイ、ドメイン別プロジェクトテンプレートを使って、モデルの振る舞いを検証可能、追跡可能、反復可能にする方法。

本教材では、できる限り一貫した題材を使います。まず「契約条項のリスク検出」から始め、法律 QA の RAG、ドメイン微調整、評価、安全な回答拒否、モデルカードへと進みます。医療 QA は 2 つ目の高リスク領域の事例として扱い、安全境界と人間によるレビューの重要性を強調します。

## 本教材で扱わないこと

- Python の文法からは始めません。
- LLM を prompt テクニックだけに還元しません。
- ただ動くだけの demo を並べることはしません。
- 「loss が下がった」ことを厳密な評価の代わりにはしません。
- RAG、LoRA、蒸留をひとまとめの曖昧な概念として扱いません。

## 各章の標準成果物

各章には少なくとも次の内容が含まれます。

- `lessons/xx_*.md`: 問いを積み重ねる形式の本文。
- `notebooks/xx_*.ipynb`: 対話的に実行できる実験。
- `src/`: 再利用可能な実装。
- `tests/`: 振る舞いを検証する受け入れテスト。
- その章の失敗実験: よくある誤りと診断方法。

各章では、必ず次の問いに答えます。

1. 現在埋めようとしている能力のギャップは何か。
2. 重要な数学的対象は何か。
3. 入力、出力、パラメータ、loss の shape はどうなっているか。
4. 最小実装は何か。
5. それを観察する実験をどのように設計するか。
6. よくある失敗パターンは何か。
7. tests は実装が壊れていないことをどのように証明するか。

## 第 1 章の学習契約

第 1 章は「MLP をとりあえず動かす」章ではありません。以降のすべての章で使い続ける訓練の作法を身につける章です。

- 訓練ループ: `forward -> loss -> backward -> optimizer.step`。
- 計算グラフ: autograd が何を記録し、何を逆伝播するのかを理解する。
- train/val: 訓練データでの性能は汎化性能と同じではない。
- 再現可能な実験: seed、データ分割、shuffle、初期化を固定する。
- overfit tiny: 小さなデータセットすら過学習できない場合、訓練パイプラインにバグがある可能性が高い。
- tests は smoke test ではない: パラメータ更新、loss の低下、eval 時に勾配が発生しないこと、train/eval モードの違いを検証する。

## クイックスタート

`venv` を使う場合:

```bash
python3.10 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

Conda を使う場合:

```bash
conda env create -f environment.yml
conda activate llm-from-zero
pip install -e ".[dev]"
```

すべてのテストを実行:

```bash
pytest -q
```

第 1 章の基礎訓練実験を実行:

```bash
python -m src.training.simple_mlp --experiment baseline
```

第 1 章の小規模データ過学習実験を実行:

```bash
python -m src.training.simple_mlp --experiment overfit_tiny
```

notebook を起動:

```bash
jupyter lab
```

その後、対応する章の notebook を開きます。例: `notebooks/01_tensor_autograd.ipynb`。

## ディレクトリ構成

- `lessons/`: 問いを積み重ねる形式で書かれた中国語の教材本文。
- `notebooks/`: 読みながら実行するための教育用 notebook。
- `src/`: 最小限の訓練モジュールから、言語モデル、微調整、RAG、蒸留、評価へと発展する再利用可能なコード。
- `tests/`: shape、数値的な振る舞い、訓練の挙動、再現性、失敗パターンを pytest で検証するテスト。
- `projects/`: 法律契約レビュー、医療 QA アシスタントなどの垂直領域プロジェクトテンプレート。
- `reports/`: モデル評価レポートと model card のテンプレート。
- `workflows/`: Pro + Codex による協調執筆ワークフロー。
